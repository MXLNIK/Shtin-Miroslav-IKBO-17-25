# Инструмент командной строки для учебного конфигурационного языка

# Общее описание

Проект представляет собой транслятор конфигурационного языка в формат XML.
Программа написана на Python и использует библиотеку Lark для синтаксического анализа.
Исходный текст конфигурации поступает через стандартный ввод, после синтаксического разбора и вычисления выражений программа преобразует данные в XML и сохраняет результат в указанный файл.

В проекте реализованы:
- восьмеричные числа;
- переменные;
- сложение;
- функция abs;
- константные выражения;
- словари;
- вложенные словари;
- многострочные комментарии;
- обработка синтаксических ошибок.

# Описание всех функций и настроек

## Синтаксис языка

| Конструкция | Пример | Назначение |
|---|---|---|
| Число | `0o10` | Восьмеричное число |
| Переменная | `var port := 0o50` | Объявление переменной |
| Использование переменной | `port` | Получение значения |
| Сложение | `0o10 + 0o20` | Сложение чисел |
| Абсолютное значение | `abs(0o10)` | Вычисление модуля |
| Константа | `.{0o10 + 0o20}.` | Вычисление константного выражения |
| Словарь | `dict(port = 0o50)` | Создание словаря |
| Вложенный словарь | `dict(server = dict(port = 0o50))` | Создание вложенного словаря |
| Комментарий | `--[[ текст ]]` | Многострочный комментарий |

## Функции программы

### config_parser.py

- `create_parser()` – создает синтаксический анализатор.
- `parse_text(text)` – преобразует исходный текст в синтаксическое дерево.

### evaluator.py

- `ConfigEvaluator` – выполняет вычисление конструкций языка.
- `start(items)` – обрабатывает все конструкции.
- `number(items)` – преобразует восьмеричное число.
- `variable(items)` – сохраняет переменную.
- `variable_name(items)` – получает значение переменной.
- `expression(items)` – вычисляет сумму.
- `absolute(items)` – вычисляет абсолютное значение.
- `constant(items)` – обрабатывает константное выражение.
- `pair(items)` – создает пару имени и значения.
- `dictionary(items)` – преобразует пары в словарь.
- `evaluate_text(text)` – выполняет разбор и вычисление текста.

### xml_converter.py

- `add_dictionary(parent, dictionary)` – добавляет словарь в XML.
- `add_value(parent, value)` – добавляет значение в XML.
- `convert_to_xml(values)` – преобразует результаты в XML.

### main.py

- `create_argument_parser()` – создает обработчик аргументов.
- `translate_text(text)` – выполняет трансляцию текста в XML.
- `main()` – запускает программу, читает стандартный ввод и сохраняет результат.

## Настройки

| Настройка | Назначение |
|---|---|
| `-o` | Указывает выходной XML-файл |
| `--output` | Полная форма параметра `-o` |
| `OCTAL_BASE` | Основание системы счисления |
| `XML_ENCODING` | Кодировка XML |
| `ROOT_TAG` | Название корневого XML-элемента |

# Описание команд для сборки проекта и запуска тестов

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
python -m unittest discover -s tests -v
```

## Запуск транслятора

```bat
run.bat -o result.xml < examples/server.conf
```

Программа читает конфигурацию из стандартного ввода и сохраняет результат в XML-файл.

# Примеры использования

## Пример 1. Веб-сервер

Файл: `examples/server.conf`

Запуск:

```bat
run.bat -o server.xml < examples/server.conf
```

## Пример 2. Компьютерная сеть

Файл: `examples/network.conf`

Запуск:

```bat
run.bat -o network.xml < examples/network.conf
```

## Пример 3. Складская система

Файл: `examples/warehouse.conf`

Запуск:

```bat
run.bat -o warehouse.xml < examples/warehouse.conf
```
