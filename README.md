# Эмулятор оболочки ОС

## Общее описание

Консольный эмулятор командной оболочки, написанный на Python.

## Описание всех функций и настроек

На первом этапе реализованы:

- Интерактивный консольный интерфейс (REPL).
- Приглашение с именем пользователя, именем компьютера и текущим путём.
- Раскрытие переменных окружения реальной операционной системы.
- Команда `ls` – заглушка, выводящая имя и аргументы.
- Команда `cd` – заглушка, выводящая имя и аргументы.
- Команда `exit` – завершение работы.
- Обработка неизвестных команд и неверных аргументов.

## Описание команд для сборки проекта и запуска тестов

Установка дополнительных библиотек не требуется.

Запуск:

```bat
./run.bat
```

Запуск тестов:

```bash
python -m unittest discover -s tests -v
```

## Примеры использования

```text
student@computer:~$ ls
Команда: ls, аргументы: []
student@computer:~$ ls folder
Команда: ls, аргументы: ['folder']
student@computer:~$ cd ..
Команда: cd, аргументы: ['..']
student@computer:~$ unknown
Ошибка: неизвестная команда 'unknown'.
student@computer:~$ cd one two
Ошибка: команда cd принимает не более одного аргумента.
student@computer:~$ exit
```
