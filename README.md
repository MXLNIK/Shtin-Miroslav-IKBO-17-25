# Эмулятор оболочки ОС

## Общее описание

Консольный эмулятор командной оболочки, написанный на Python.

## Описание всех функций и настроек

### Этап 1. REPL

- Интерактивный консольный интерфейс (REPL).
- Приглашение с именем пользователя, именем компьютера и текущим путём.
- Раскрытие переменных окружения реальной операционной системы.
- Команда `ls` – заглушка, выводящая имя и аргументы.
- Команда `cd` – заглушка, выводящая имя и аргументы.
- Команда `exit` – завершение работы.
- Обработка неизвестных команд и неверных аргументов.

### Этап 2. Конфигурация

- Параметр `--vfs PATH` задаёт путь к физическому расположению VFS.
- Параметр `--script PATH` задаёт путь к стартовому скрипту.
- При запуске выводятся все параметры конфигурации в формате `ключ=значение`.
- Команда `conf-dump` повторно выводит параметры конфигурации.
- Стартовый скрипт выполняет команды последовательно.
- Ошибочные команды пропускаются, выполнение скрипта продолжается.
- Во время выполнения скрипта отображаются вводимые команды и их результаты.
- BAT-скрипты демонстрируют разные варианты запуска.

## Описание команд для сборки проекта и запуска тестов

Установка дополнительных библиотек не требуется.

Запуск:

```bat
./run.bat
```

Запуск тестов:

```bash
python -m unittest discover -s tests -v
```

## Примеры использования

```text
student@computer:~$ conf-dump
vfs=None
script=None
student@computer:~$ ls documents
Команда: ls, аргументы: ['documents']
student@computer:~$ unknown
Ошибка: неизвестная команда 'unknown'.
student@computer:~$ exit
```

Запуск стартового скрипта:

```bash
python src/main.py --vfs vfs.json --script scripts/startup.txt
```

В начале выполнения выводятся заданные параметры, затем команды скрипта и результаты их выполнения.

Доступные BAT-скрипты:

- `scripts/test_default.bat` — запуск со стартовым скриптом.
- `scripts/test_vfs.bat` — запуск с параметром `--vfs`.
- `scripts/test_script.bat` — запуск с обоими параметрами в обратном порядке.
