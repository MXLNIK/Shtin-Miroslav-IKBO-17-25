# Эмулятор оболочки ОС

## Общее описание

Консольный эмулятор командной оболочки на Python. Проект включает в себя интерактивный интерфейс, параметры запуска, стартовые скрипты и виртуальную файловую систему (VFS).

Все операции с виртуальными файлами и каталогами выполняются в памяти. JSON-файлы используются как источник данных VFS.

## Описание всех функций и настроек

### Этап 1. REPL

- Интерактивный консольный интерфейс (REPL).
- Приглашение с именем пользователя, именем компьютера и текущим путём.
- Раскрытие переменных окружения реальной операционной системы.
- Команда `ls` – заглушка, выводящая имя и аргументы.
- Команда `cd` – заглушка, выводящая имя и аргументы.
- Команда `exit` – завершение работы.
- Обработка неизвестных команд и неверных аргументов.

### Этап 2. Конфигурация

- Параметр `--vfs PATH` задаёт путь к физическому расположению VFS.
- Параметр `--script PATH` задаёт путь к стартовому скрипту.
- При запуске выводятся все параметры конфигурации в формате `ключ=значение`.
- Команда `conf-dump` повторно выводит параметры конфигурации.
- Стартовый скрипт выполняет команды последовательно.
- Ошибочные команды пропускаются, выполнение скрипта продолжается.
- Во время выполнения скрипта отображаются вводимые команды и их результаты.
- BAT-скрипты демонстрируют разные варианты запуска.

### Этап 3. VFS

- Загрузка виртуальной файловой системы из JSON.
- Хранение файлов и каталогов в памяти.
- Поддержка вложенных каталогов.
- Поддержка текстовых файлов и двоичных данных Base64.
- Команда `ls` для просмотра содержимого виртуальных каталогов.
- Команда `cd` для перехода по виртуальным каталогам.
- Команда `pwd` для вывода текущего виртуального пути.
- Команда `cat` для чтения виртуальных файлов.
- Команда `vfs-init` для сброса VFS к состоянию по умолчанию.
- Обработка отсутствующих путей и некорректных команд.

## Описание команд для сборки проекта и запуска тестов

Установка дополнительных библиотек не требуется.

Запуск:

```bat
./run.bat
```

Запуск тестов:

```bash
python -m unittest discover -s tests -v
```

Доступные тестовые сценарии:

- `scripts/test_default.bat` – запуск со стартовым скриптом `startup.txt`.
- `scripts/test_vfs.bat` – запуск с параметром `--vfs`.
- `scripts/test_script.bat` – запуск с обоими параметрами в обратном порядке.

Тестовые данные:

- `vfs/minimal.json` – минимальная VFS.
- `vfs/files.json` – несколько файлов и вложенный каталог.
- `vfs/nested.json` – многоуровневая структура каталогов.
- `scripts/startup.txt` – проверка команд и ошибок.
- `scripts/test_all.txt` – проверка VFS и вложенных каталогов.

## Примеры использования

```text
student@computer:~$ conf-dump
vfs=None
script=None
student@computer:~$ ls documents
Команда: ls, аргументы: ['documents']
student@computer:~$ unknown
Ошибка: неизвестная команда 'unknown'.
student@computer:~$ exit
```

Запуск с JSON-файлом VFS:

```bash
python src/main.py --vfs vfs/files.json
```

Запуск со стартовым скриптом:

```bash
python src/main.py --script scripts/startup.txt
```

Запуск с VFS и скриптом:

```bash
python src/main.py --vfs vfs/nested.json --script scripts/test_all.txt
```

В начале выполнения выводятся заданные параметры, затем команды скрипта и результаты их выполнения.
