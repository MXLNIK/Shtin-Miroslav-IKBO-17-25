# Инструмент визуализации графа зависимостей

## Общее описание

Консольное приложение на языке Python для анализа и визуализации зависимостей Java-пакетов из Maven-репозитория.

Программа получает информацию о зависимостях пакета, строит граф прямых и транзитивных зависимостей и сохраняет результат в формате SVG. Также поддерживается генерация текстового представления графа в формате Mermaid.

Основные возможности приложения:

- получение POM-файлов из Maven-репозитория;
- извлечение информации о зависимостях пакетов;
- обработка версий, указанных через Maven properties и родительские POM;
- построение графа зависимостей с использованием обхода в ширину (BFS);
- ограничение глубины анализа зависимостей;
- фильтрация зависимостей по подстроке;
- обработка циклических зависимостей;
- генерация Mermaid-диаграммы;
- создание SVG-файла с визуальным представлением графа;
- использование локального тестового репозитория в JSON-формате.

Проект не требует установки сторонних Python-библиотек и использует стандартные средства Python.

## Описание всех функций и настроек

### Описание модулей

**`main.py`**

Главный модуль приложения. Выполняет следующие действия:
- загружает настройки;
- проверяет корректность конфигурации;
- получает зависимости выбранного пакета;
- строит граф зависимостей;
- формирует порядок загрузки пакетов;
- генерирует Mermaid- и SVG-представления;
- сохраняет результат в файл.

**`config.py`**

Отвечает за чтение и проверку настроек из `config.ini`.

Основные функции:
- `load_config()` — загружает параметры приложения;
- `validate_config()` — проверяет корректность настроек.

**`repository.py`**

Отвечает за взаимодействие с Maven-репозиторием.

Основные функции:
- `build_pom_url()` — формирует URL POM-файла;
- `download_pom()` — загружает POM-файл;
- `find_element()` — ищет XML-элемент с учетом пространства имен;
- `get_text()` — получает текст XML-элемента;
- `resolve_properties()` — подставляет значения Maven properties;
- `get_properties()` — получает свойства POM-файла;
- `get_managed_versions()` — получает версии зависимостей из `dependencyManagement`;
- `load_pom_context()` — загружает информацию из POM и родительских POM;
- `parse_dependencies()` — извлекает зависимости с явно указанными версиями;
- `extract_dependencies()` — извлекает зависимости с учетом свойств и управляемых версий;
- `get_dependencies()` — получает зависимости конкретного Maven-пакета;
- `get_maven_graph()` — строит граф Maven-зависимостей.

**`graph.py`**

Отвечает за работу с графом зависимостей.

Основные функции:
- `load_test_repository()` — загружает тестовый граф из JSON;
- `validate_graph()` — проверяет структуру тестового графа;
- `get_test_dependencies()` — получает прямые зависимости пакета;
- `build_graph()` — строит граф зависимостей с помощью обхода в ширину (BFS).

При построении графа учитываются максимальная глубина анализа, фильтрация и уже посещенные узлы.

**`ordering.py`**

Отвечает за определение порядка загрузки пакетов с учетом их зависимостей.

**`visualization.py`**

Отвечает за визуальное представление графа.

Основные функции:
- `generate_mermaid()` — создает текстовое представление графа в формате Mermaid;
- `get_levels()` — распределяет узлы графа по уровням;
- `get_positions()` — рассчитывает координаты узлов;
- `add_edges()` — добавляет связи между узлами;
- `add_nodes()` — добавляет графические блоки и подписи;
- `generate_svg()` — создает SVG-файл с графом зависимостей.

### Описание настроек

Параметры приложения задаются в файле `config.ini`.

Пример конфигурации:

```ini
[settings]
package_name = org.apache.httpcomponents:httpclient:4.5.14
repository_url = https://repo1.maven.org/maven2
test_repository = test_repository.json
test_mode = false
output_file = graph.svg
max_depth = 3
filter_substring =
```

Описание параметров:

| Параметр | Назначение |
|---|---|
| `package_name` | Координаты Maven-пакета в формате `group:artifact:version` |
| `repository_url` | URL Maven-репозитория |
| `test_repository` | Путь к локальному тестовому JSON-файлу |
| `test_mode` | Включает или отключает использование тестового репозитория |
| `output_file` | Имя выходного SVG-файла |
| `max_depth` | Максимальная глубина анализа зависимостей |
| `filter_substring` | Подстрока для исключения зависимостей, содержащих указанное значение |

При `test_mode = true` программа использует локальный тестовый репозиторий.

При `test_mode = false` программа получает данные из указанного Maven-репозитория.

Пустое значение `filter_substring` означает, что фильтрация не применяется.

## Описание команд для сборки проекта и запуска тестов

### Требования

Для работы приложения необходимы:
- Python версии 3.10 или выше;
- Git;
- подключение к интернету для получения данных из Maven-репозитория.

Сторонние Python-библиотеки устанавливать не требуется.

### Запуск приложения

Для запуска приложения используется команда:

```powershell
python -m src.main
```

Также предусмотрен запуск с помощью командного файла:

```powershell
run.bat
```

### Запуск тестов

Для запуска всех автоматических тестов используется команда:

```powershell
python -m unittest discover -s tests -v
```

Для запуска тестов отдельного модуля:

```powershell
python -m unittest tests.test_config -v
python -m unittest tests.test_repository -v
python -m unittest tests.test_graph -v
python -m unittest tests.test_ordering -v
python -m unittest tests.test_visualization -v
```

## Примеры использования

### Анализ пакета Apache

В файле `config.ini` указываются параметры:

```ini
[settings]
package_name = org.apache.httpcomponents:httpclient:4.5.14
repository_url = https://repo1.maven.org/maven2
test_repository = test_repository.json
test_mode = false
output_file = graph.svg
max_depth = 3
filter_substring =
```

Запуск:

```powershell
python -m src.main
```

В результате программа получает информацию о зависимостях пакета и создает файл `graph.svg`.

### Использование тестового режима

Для проверки работы программы без обращения к Maven Central можно включить тестовый режим:

```ini
[settings]
package_name = A
repository_url = https://repo1.maven.org/maven2
test_repository = test_repository.json
test_mode = true
output_file = test_graph.svg
max_depth = 3
filter_substring =
```

При запуске:

```powershell
python -m src.main
```

Программа использует данные из `test_repository.json` и создает файл `test_graph.svg`.
